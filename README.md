## Exercici 3 — Plantilles administratives amb LibreOffice Writer

A la carpeta [Ubuntu/LibreOffice/Exercici 3](https://github.com/igarcia21404-dev/UD2.AO/tree/linux-entrega-rehecha/Ubuntu/LibreOffice/Exercici%203) (branca `linux-entrega-rehecha`) hi ha les sis plantilles en català:

1. **Anunci** — Ajuntament de Maó: obertura del termini de matriculació als cursos de Ceràmica, Música i Dibuix de l'Escola Municipal.
2. **Carta** — IES Joan Ramis i Ramis sol·licita 2 multifuncions a Xerox de Menorca.
3. **Certificat** — El secretari del centre certifica que l'alumne cursa 1r SMX.
4. **Circular** — Servei de Recaptació de l'Ajuntament de Maó: termini fins al proper mes d'abril per pagar el rebut de l'IBI.
5. **Citació** — Hisenda demana comparèixer un dia i hora concrets per signar documentació del Model 061.
6. **Contracte** — Model de compravenda d'habitatge.

### Formats
- Fitxers **.fodt** (Flat OpenDocument XML) editables directament.
- **Plantilles_Administratives_UD2AO.zip** amb els sis documents en format **.odt**.

Obriu amb LibreOffice Writer → **Fitxer → Anomena i desa → Text ODF (.odt)** si cal.

### Estils aplicats
- Pàgina A4, marges ~2 cm.
- Tipografia Liberation Sans, títols en color, paràgrafs justificats, interlineat 120%.
- Capçaleres/peus de pàgina, jerarquia de títols i seccions.
- Revisió ortogràfica en català (Eines → Llengua / F7). Instal·lar diccionari català si cal.

Consulteu el README de la carpeta de l'exercici per a més detalls i notes de rigor.
