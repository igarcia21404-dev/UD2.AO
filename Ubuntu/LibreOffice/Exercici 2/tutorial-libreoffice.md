# Minitutorial — LibreOffice Writer a Linux

1. Obriu Writer i feu una captura real abans dels canvis.
2. Visualitza → Barres d'eines: activeu Estàndard, Formatació i Dibuix.
3. Eines → Personalitza → Barres d'eines: afegiu Ortografia, Exporta PDF, Taula, Imatge, Color de lletra i Ressaltat.
4. Eines → Opcions → LibreOffice Writer → Tipus de lletra bàsics: Liberation Sans 11 pt.
5. Eines → Opcions → Configuració de la llengua: seleccioneu Català si el paquet lingüístic és instal·lat.
6. Eines → Ortografia: comproveu el diccionari; instal·leu el diccionari català des del gestor d'extensions si falta.
7. Feu una captura real després dels canvis.

Evidències: `abans-libreoffice.png` i `despres-libreoffice.png` (captures de la vostra MV).
