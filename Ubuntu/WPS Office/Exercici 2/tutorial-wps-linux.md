# Minitutorial — WPS Writer a Linux

1. Obriu WPS Writer i feu una captura real abans dels canvis.
2. Manteniu accessibles les pestanyes Home, Insert i Review.
3. A Menu → Settings/Options reviseu la llengua d'edició i la correcció ortogràfica; si el català no hi és, indicau-ho.
4. Personalitzeu la barra d'accés ràpid amb Desa, Desfés, Refés, Imprimeix i Exporta PDF.
5. Configureu font llegible (Arial 11 pt), interlineat 1,15 i marges normals.
6. Deseu i feu una captura real després dels canvis.

Evidències: `abans-wps.png` i `despres-wps.png`. Els menús poden variar segons la versió.
