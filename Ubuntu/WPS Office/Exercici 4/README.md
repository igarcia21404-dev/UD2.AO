# Exercici 4 — WPS Office (plantilles .docx)

Plantilles creades amb processador de textos (compatible WPS Office / LibreOffice / Microsoft Word).

## Contingut

| Núm. | Fitxer | Descripció |
|------|--------|------------|
| 1 | `01_Convocatoria_reunio.docx` | Convocatòria de reunió del Club Marítim de Maó |
| 2 | `02_Curriculum_vitae.docx` | Currículum vitae modern |
| 3 | `03_Factura.docx` | Factura d'empresa de material informàtic |
| 4 | `04_Sollicitud_instancia.docx` | Sol·licitud / Instància per a concurs-oposició |
| 5 | `05_Document_dues_columnes.docx` | Document a dues columnes (estil diari comarcal) |
| 6 | `06_Diploma.docx` | Diploma de millor alumne de 1r de SMX |
| 7 | `07_Document_imatge_fons.docx` | Document amb imatge de fons (Unsplash, llicència lliure) |

## Característiques aplicades

- Canvi d'estils de font (tipus, mida, color, negreta, cursiva)
- Format de paràgraf (alineació, interlineat, sagnats)
- Marges personalitzats
- Capçaleres i peus de pàgina
- Taules formatades
- Columnes (document 5)
- Orientació horitzontal (diploma)
- Inserció d'imatge respectant drets d'autor
