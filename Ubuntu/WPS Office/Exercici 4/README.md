# Exercici 4 — Plantilles amb WPS Office (.docx)

Set de 7 plantilles creats amb WPS Office / processador de text compatible, guardats en format **.docx**.

## Documents

1. **01_Convocatoria_reunio_Club_Maritim.docx**  
   Convocatòria del Club Marítim de Maó als socis (dilluns 20 h, sala d'actes).

2. **02_Curriculum_vitae_modern.docx**  
   CV modern i net, pensat per a estudiant de 1r SMX (camps personalitzables).

3. **03_Factura.docx**  
   Factura d'Informàtica Maó S.L. amb productes (multifuncions, toner, paper, instal·lació).

4. **04_Solicitud_Instancia.docx**  
   Sol·licitud / instància per prendre part en un concurs-oposició de plaça administrativa.

5. **05_Document_dues_columnes_diari.docx**  
   Document d'estil diari comarcal amb **dues columnes** i text de notícies locals.

6. **06_Diploma_millor_alumne_SMX.docx**  
   Diploma de "Millor alumne/a de 1r de SMX" expedit per l'IES Joan Ramis i Ramis (orientació horitzontal).

7. **07_Document_imatge_fons.docx**  
   Document amb imatge de fons (fotografia d'Unsplash, llicència lliure). Inclou instruccions per configurar-la com a fons real a WPS Writer.

## Estils aplicats
- Tipografies: Calibri, Arial, Georgia, Times New Roman
- Colors institucionals, títols, paràgrafs justificats / centrats
- Marges ~1,5–2,5 cm, capçaleres i peus de pàgina
- Taules, ombrejats, bordes i jerarquia visual
- Revisió ortogràfica: obriu a WPS Writer, seleccioneu català i executeu el corrector (F7)

## Com usar
Obriu els fitxers amb **WPS Writer** (o LibreOffice / Microsoft Word). Personalitzeu els camps entre claudàtors `[ ]`.

## Imatge de fons
La imatge de `07_Document_imatge_fons.docx` prové d'**Unsplash** (ús lliure). Per establir-la com a fons de pàgina a WPS:  
**Disseny de pàgina → Fons → Imatge** i seleccioneu el fitxer descarregat.
